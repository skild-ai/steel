# Steel site

The Steel docs and tutorials, built with [Astro](https://astro.build) and
[Starlight](https://starlight.astro.build) into a static site.

```bash
npm ci
npm run dev       # http://localhost:4321, reloads on edits
npm run build     # static site in dist/, then a check of every internal link and anchor and of the examples
npm run preview   # serve dist/
npm run check-figures   # every page in headless Chromium: figures render, no console errors, no clipped table
npm run check-replay    # tutorial replays start from 0 s on load, navigation, slow loads and stalls
npm run check-clips     # example clips play, keep an early seek, change speed, and play one at a time
```

Node 22.23.4 or newer (see `.nvmrc`). `check-figures`, `check-replay` and `check-clips` need a Chromium: `npx playwright-core install chromium`,
or point `STEEL_CHROME` at one. Set `STEEL_SITE_BASE=/docs/` to build for a subpath,
`INSIDE_STEEL_URL` to point the "Inside Steel" link at the hosted post, and `STEEL_ALLOWED_HOSTS` (comma
separated) to reach `npm run dev -- --host` or `npm run preview -- --host` by a machine name instead of
localhost or an IP address.

## Where things are

```
src/content/docs/        pages (Markdown or MDX); the folder is the sidebar group
src/components/          Figure, Note, CardGrid/InfoCard, Viz (interactive figure), Term (concept bubble)
src/viz/                 the interactive figures: one SteelViz module each, _lib.js helpers, terms.js, series.json
src/components/demos/    larger demos as Astro components (markup, styles and script)
src/components/figures/  static figures
src/components/reference/ the generated reference: options browser and tables
src/components/tutorials/ the tutorial replay viewer, cost table and concept block
src/lib/stage3d.ts       three.js helpers: the Steel studio look and a small orbit stage
src/lib/replay/viewer.ts the tutorial replay
src/lib/tutorials-data.mjs reads ../tutorials at build time
src/pages/tutorials/     the tutorial index and one generated page per tutorial
src/pages/examples/      the examples gallery and one generated page per example
src/lib/examples-data.mjs reads ../examples/shelf at build time
public/examples/<name>/  each example's poster.jpg, preview.mp4 (gallery hover) and clip.mp4 (its page)
src/styles/steel-tokens.css the shared Steel style tokens (replace the whole file to update them)
src/styles/steel.css     maps the tokens onto Starlight and styles the shared components
src/data/reference.json  generated by scripts/gen_reference.py
scripts/                 gen_reference.py, gen_changelog.py, check-links.mjs, check-examples.mjs, example_media.py, experiments/
```

Example pages come from `../examples/shelf`: a new example gets a card and a page with a placeholder, and
`scripts/check-examples.mjs` fails on a card, page or media folder without its example. `scripts/example_media.py`
makes an example's media from a recording of its Steel preset (see [Contributing](src/content/docs/contributing.mdx)).

Tutorial pages come from `../tutorials` (scripts, page text and recordings); see
[tutorials/README.md](../tutorials/README.md). The changelog page renders `../CHANGELOG.md`.

## Regenerating data

```bash
# the configuration reference, from a Newton clone with the upstream remote fetched
python scripts/gen_reference.py --source path/to/newton \
    --refs "Newton 1.8.0=v1.8.0" "Newton main=upstream/main"

# the changelog (needs the GitHub CLI); writes ../CHANGELOG.md
python scripts/gen_changelog.py --repo path/to/newton --upstream upstream/main --release v1.8.0 \
    --branch <integration-branch-ref>
```

See [CONTRIBUTING.md](../CONTRIBUTING.md#documentation-site-and-tutorials) for how to add pages, demos
and tutorials.
